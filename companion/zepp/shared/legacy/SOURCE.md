# Zepp API 1.0 transport

Modules from the official [Zepp Health Fetch API 1.0 sample](https://github.com/zepp-health/zeppos-samples/tree/main/application/1.0/fetch-api/shared), downloaded 2026-10-20. Apache-2.0 license is included in LICENSE.txt. These polyfills and MessageBuilder use the legacy hmBle/messaging APIs without importing API 2/3 modules.

Local changes: request timeout/error listener cleanup in message.js.
